# 02 — 参照行情与 TOPIX 均线

**Status:** ready-for-agent
**Blocked by:** 01
**Spec:** [TOPIX ETF 策略](../spec.md)

第二个纵向切片：让策略能读取但不交易 TOPIX（参照行情），并交付第一个按 TOPIX 趋势决定持有 1306 还是空仓的策略。

## 用户可见的交付

1. 新建账户页能选「TOPIX 均线」，参数有三个：均线窗口（默认 200）、缓冲带（默认 1%，即 0.01）、预热期（默认 200）。页面提示的预热期跟着窗口变；预热期设得比窗口短时，建账户被拒绝并说明原因。
2. 买卖规则：
   - TOPIX 收盘高出均线超过缓冲带时，账户在下一开市日开盘买入 1306；
   - TOPIX 收盘低于均线超过缓冲带时，账户在下一开市日开盘全部卖出，之后持有现金；
   - 落在缓冲带内（含恰好在门槛上）时不改变状态；
   - 缓冲带设成 0 时，退化为「高于均线就买、低于均线就卖」。
3. 信号页：有候选时显示 1306，理由「TOPIX 在均线之上」；没有候选时写明「今天不持有 1306」，并附上到 1306 详情页的链接。
4. 1306 的证券详情页在单独一栏画 TOPIX 收盘和均线，并标出空仓时会买入的日期。
5. TOPIX 永远不出现在入场候选、订单或持仓里。

## 实现检查项

- [ ] **策略声明参照行情**：策略协议增加「参照行情」声明，作为属性，默认空，现有策略和 01 的对照组取默认值。`evaluate` 的约定补充：
  - 参照行情的代码只作为输入，永远不出现在返回的信号里；
  - frame 里其余每只能判断的证券照常得到一条信号。
- [ ] **调用方把参照行情加进读取范围**：
  - 信号页：股票池 ∪ 参照行情；
  - 证券详情页：该证券 ∪ 参照行情；
  - 模拟账户推进：整段股票池的并集 ∪ 持仓 ∪ 挂单 ∪ 参照行情。
  - 建账户时的预热期校验不变，仍按 TOPIX 的开市日数计。
- [ ] **共用基类（可选）**：统一处理「用参照行情算线，对池内证券给信号」，03 的动量策略也会用它。现有两个个股策略的实现不动。
- [ ] **新策略 `topix_ma_v1`**，参照行情为 TOPIX，股票池规则为 TOPIX ETF，每个开市日收盘判断：
  - **计算**：均线 = 含当天在内最近 `ma_sessions`（默认 200）个 TOPIX 收盘的简单平均。窗口按 TOPIX 有收盘的开市日往前数，和指标模块对缺失日的规则一致。偏离 = TOPIX 收盘 ÷ 均线 − 1。
  - **空仓时**：偏离 > `band`（默认 0.01）为可持有，理由 `topix_above_ma`，排序值 = 偏离；否则不参与，理由为 `topix_near_ma`（|偏离| ≤ `band`）或 `topix_below_ma`。
  - **持仓时**：偏离 < −`band` 为必须清仓，理由 `topix_below_ma`；否则可持有。
  - **没有信号的情况**：当天 TOPIX 没有收盘，或窗口内收盘不够。
  - **预热期**：`warmup_sessions` 默认 200，比 `ma_sessions` 小时拒绝建策略；未知参数照旧拒绝。
  - **指标值和画线**：指标值含 TOPIX 收盘、均线、偏离；在单独一栏画 TOPIX 收盘和均线。
  - 策略名不写死窗口长度；不读、不复用 `topix_trend_vol_v1` 的形势标签。
- [ ] **前端**：
  - 策略名称「TOPIX 均线」和说明；
  - 参数 `ma_sessions`、`band` 的名称和提示，`band` 写明「比例，0.01 表示 1%」；
  - 理由 `topix_above_ma`（偏买）、`topix_near_ma`（不着色）、`topix_below_ma`（偏卖）的中文说明和颜色；
  - 信号页在股票池规则为 TOPIX ETF 的策略下没有候选时，显示「今天不持有 1306」和到 1306 详情页的链接。
- [ ] **文档**：
  - CONTEXT.md 新增「参照行情（ReferenceSeries）」：策略读取但不交易的行情，例如 TOPIX。它不同于基准（只用于对比、不参与信号），也不同于市场形势（与策略无关）；
  - 「策略」的定义加入参照行情；
  - 注明 TOPIX ETF 策略的条件是策略自己的规则，不用「择时模型」「择时信号」这类说法；
  - 系统设计新增「TOPIX ETF 策略」小节，写入一直持有和均线的规则；§6.2 和附录 A.3 写入参照行情声明。

## 测试与验收

- [ ] **策略 seam**：合成 frame 里有 TOPIX 和一只 ETF 两列。先例：`test_trend_pullback_rules`、`test_technical_rating_rules`、`test_strategy_evaluate`。要覆盖：
  - 偏离高于、等于、低于门槛时，空仓和持仓各自的处置和理由；
  - 默认缓冲带 1% 的两条门槛；缓冲带设成 0 时的退化行为；
  - 排序值 = 偏离；
  - 差一个收盘时没有信号，够了才有；
  - 当天 TOPIX 缺收盘时没有信号；ETF 不可交易时没有信号；
  - TOPIX 不出现在信号里；
  - 截到 t 日评价，结果和用整个 frame 相同（不看未来）；
  - 未知参数、预热期短于窗口都被拒绝；
  - 指标值里有画线用的名字。
- [ ] **模拟账户**：在合成行情上，TOPIX 向上越过上门槛后买入 1306，向下越过下门槛后全部卖出、持有现金；在缓冲带内不动；TOPIX 被读到，但不出现在订单和持仓里。
- [ ] **API**：
  - 信号接口在这个策略下返回 1306 或空列表；
  - 1306 的行情接口返回 TOPIX 收盘、均线两条线和入场日。
- [ ] **前端**（先例：信号页、证券详情页、新建账户页的测试）：没有候选时的说明和链接；参数与理由文字；预热期提示跟着窗口变化。
- [ ] **真实数据演示**：在数据库副本上做。
  - 用 2022-10-06 建账户（默认参数），推进到最新交易日。
  - 记录每次买卖的日期和理由、成交次数、总收益、最大回撤、相对 TOPIX 的超额，和 01 的对照组账户放在一起比较。
  - 进出次数对照下面 Comments 里的预计值：约 19 次，最后一次买入在 2025-05 前后。
  - 留一张 1306 详情页截图。
  - 记录追加在本文件末尾的 `## Comments` 下。

## 不在本步范围

- TOPIX 动量（03）；用 TOPIX 条件限制个股策略开仓（05 的 `gate_new_entries`）；研究回测支持；均线的按月判断版本。

## Comments

### 2026-10-02 规则修订：缓冲带默认 1%，策略改名

开工前、和用户确认后修订，两处改动：

- 缓冲带默认值从 0 改为 1%；
- 策略名从 `topix_sma200_v1` 改为 `topix_ma_v1`。窗口是可调参数，名字里不再写死 200。

依据是对真实 TOPIX 数据的只读模拟：2022-10-06 至 2026-10-01，只数进出次数，没算收益。

| 规则 | 持有天数占比 | 进出次数 |
|---|---|---|
| 200 日均线，每天判断，缓冲 0 | 89% | 43 |
| 200 日均线，每天判断，缓冲 1% | 88% | 19 |

缓冲 0 时，TOPIX 在均线附近会来回穿越，产生大量短进短出。完整记录和披露要求见规格「补充说明 · 进出次数检查」。
