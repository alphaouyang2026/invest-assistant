# 03 — TOPIX 动量与三账户对比验收

**Status:** done
**Blocked by:** 02
**Spec:** [TOPIX ETF 策略](../spec.md)

最后一个切片：用 02 的参照行情机制加入第二个按 TOPIX 趋势进出的策略，然后在真实数据上把三个策略并排验收。

## 用户可见的交付

1. 新建账户页能选「TOPIX 动量」，参数有两个：回看长度（默认 252 个开市日，约 12 个月）、预热期（默认 253）。策略说明写明「每月第一个开市日判断，月中建的账户等到下个月才可能买入」。
2. 买卖规则：只在每月第一个开市日收盘判断，下一开市日开盘成交。
   - 判断日上 TOPIX 过去收益为正，空仓的账户买入 1306；
   - 判断日上过去收益为负，持仓的账户全部卖出、持有现金；
   - 恰好为 0 时不改变状态；
   - 月中其他日子不买也不卖。
3. 1306 的证券详情页在单独一栏画 TOPIX 过去收益的曲线（每天都画），并标出空仓时会买入的日期；这些日期只会落在每月第一个开市日。
4. 一份真实数据验收记录：同一起始日的三个账户（一直持有、TOPIX 均线、TOPIX 动量）并排比较。

## 实现检查项

- [x] **新策略 `topix_momentum_v1`**，参照行情为 TOPIX，股票池规则为 TOPIX ETF：
  - **计算**：过去收益 = TOPIX 当天收盘 ÷ `lookback_sessions`（默认 252）个开市日前的收盘 − 1，只数 TOPIX 有收盘的开市日。每天都算，非判断日也一样。
  - **判断日**：当月第一个开市日。判法：frame 里当天之前最近一个有行情的日期在上个月或更早。判断日当天 TOPIX 没有收盘时，本月不判断，状态保持到下个月。判断频率属于规则本身，不开放为参数。
  - **判断日的空仓**：过去收益 > 0 为可持有，理由 `topix_momentum_up`，排序值 = 过去收益；否则不参与，理由为 `topix_momentum_flat`（等于 0）或 `topix_momentum_down`。
  - **判断日的持仓**：过去收益 < 0 为必须清仓，理由 `topix_momentum_down`；否则可持有。
  - **非判断日**：空仓不参与，理由 `not_check_day`；持仓可持有。
  - **没有信号的情况**：当天 TOPIX 没有收盘，或窗口内收盘不够。
  - **预热期**：`warmup_sessions` 默认 253，小于 `lookback_sessions` + 1 时拒绝建策略；未知参数照旧拒绝。
  - **指标值和画线**：指标值含 TOPIX 收盘和过去收益；在单独一栏画过去收益。
  - 不扣无风险利率，文档里注明：样本期日本短期利率接近 0。
  - 策略名不写死窗口长度。
- [x] **前端**：
  - 策略名称「TOPIX 动量」和说明，写明判断日规则；
  - 参数 `lookback_sessions` 的名称和提示；
  - 理由 `topix_momentum_up`（偏买）、`topix_momentum_flat`（不着色）、`topix_momentum_down`（偏卖）、`not_check_day`（不着色，「不是每月判断日」）的中文说明和颜色。
- [x] **文档**：系统设计「TOPIX ETF 策略」小节补入动量规则和判断日规则。

## 测试与验收

- [x] **策略 seam**（先例：02 的 TOPIX 均线规则测试）：
  - 判断日上过去收益为正、为 0、为负时，空仓和持仓各自的处置和理由；
  - 非判断日：空仓不参与（`not_check_day`）、持仓可持有，过去收益为正、为负都一样；
  - 判断日的判法：月初逢休市（例如 1 月 1–3 日）时，当月第一个开市日才是判断日；
  - 判断日 TOPIX 缺收盘时本月不判断，下个月判断日照常；
  - 非判断日指标值照常算出；
  - 排序值 = 过去收益；
  - 预热边界：差一个收盘时没有信号；

  - 参数校验。
