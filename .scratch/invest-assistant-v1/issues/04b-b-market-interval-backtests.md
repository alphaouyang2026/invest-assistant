**依赖：** [04b-A](04b-a-manual-range-backtest.md) 已能在页面运行手选区间并查看实际结果。

## 用户可见的交付

在 A 页面增加“按市场形势选择区间”，原手动模式继续可用：

1. 选择历史搜索范围、TOPIX 趋势和可选波动水平。
2. 系统列出所有匹配连续区间及其长度、基准变化、数据覆盖，用户勾选一段或多段。
3. 指定一个固定的策略／阈值配置，点击“对所选区间运行”。
4. 页面逐段展示进度和实际收益、TOPIX、回撤、成交数／费用；点击某段直接使用 A 的详情图表与交易记录。
5. 全部或部分完成后查看结果分布，失败段可识别及单独重试。

## 实现检查项（包括后端与页面）

- [x] 在 A 最小契约上增加版本化分类定义、发现结果及全部候选／选择集合、批次和子运行关系；同步相关设计文档，不重建另一套回放引擎。
- [x] 分类由 TOPIX 行情及交易日历产生，与策略参数／成交历史无关。采用固定工程默认 `topix_trend_vol_v1`，公式可查看，不做用户规则编辑器。
- [x] MA200 含当日 200 个收盘；gap=收盘/MA200−1；slope=MA200/20 个交易日前 MA200−1。gap>1% 且 slope>0 为上涨；gap<−1% 且 slope<0 为下跌；其余有效日期为中性／震荡候选，非确认横盘。
- [x] RV20=最近 20 个对数日收益样本标准差（ddof=1）×√252；高于当日之前 252 个 RV20 的中位数为高波动，其余低波动。历史窗口端点明确，不能用未来或全样本分位数。
- [x] 缺少所需窗口按维度标 unknown；只筛趋势时不受波动窗口不足影响。缺失开市日或非正价格不能前填成正常指数收益。趋势需要至少 220 个收盘，完整波动标签至少 273 个。
- [x] 匹配谓词的连续开市日形成最大区间；休市不切断，非匹配日／必要数据缺口切断，不合并不匹配空隙，不默认剔除短段。只筛趋势时波动切换不切断。搜索边界截断要显示。
- [x] 发现耗时工作异步提交，GET 只读状态／结果；展示公式／版本、全部区间、预热不足、缺口、短段／单日段和零匹配。
- [x] 提交引用发现 ID 及区间 ID，服务端验证归属。用户只指定一组参数；明确运行数上限，超限提示而非静默截断，保留未选择区间和选择记录。
- [x] 各段调用 A 的独立回放，每段同资金空仓，不继承前段持仓／挂单。指纹校验发现与执行数据，变化时要求重新发现／确认；同批任务受现有锁保护使用一致输入。
- [x] 保存逐段持久进度和批次状态；部分成功不当全部成功，失败不记零收益。重试留新尝试；已完成段不因重启或别段失败丢失。
- [x] UI 提供逐区间列表、A 详情入口及跨段收益／收益差分布、中位数、盈利段比例、跑赢 TOPIX 比例、最差区间、已完成／失败数量和日期覆盖。按完成区间等权且明确分母；严格>0 才算盈利／跑赢，平手单列。
- [x] 不拼接净值、不连乘独立资金的收益、不合成虚构总回撤；解释各段长度不同、多个短段可能属同一事件。边界事后可知，不能声称实时择时能力。
