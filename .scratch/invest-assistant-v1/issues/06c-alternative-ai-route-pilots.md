# 06c — 实现独立 AI 择时策略与横截面策略的风险降仓版本

**状态：** proposed；B 与 A+R 均为 06 必交。其余方向的准入卡是后续路线，不冒充已实现的策略。
**父任务：** [06 AI 完整交易策略](06-ai-strategy-research-program.md)。
**依赖：** [06a 共用评测框架](06a-research-evidence-contract.md)；B 可独立于 06b 启动，A+R 须锁定 [06b 的 A 版本](06b-cross-sectional-ai-challenge.md)，但不依赖 A 获利。
**依据：** [完整策略调查 §2–8](../../ai-complete-trading-strategy-directions.md)、[Deep Momentum Networks 原研究](https://arxiv.org/abs/1904.04912)、[现有组合规划](../../../backend/app/accounts/planning.py)。原研究的期货业绩不是日本市场证据。

## 用户可见的交付

研究工作区增加两个可分别运行的完整版本：（B）模型判断时间趋势，交易真实可买标的的长仓／现金；（A+R）完全锁定 A 的选股与退出，只由另一个风险模型改变组合总敞口。两者都显示折外模型输出、每天的买／持／卖／现金与目标权重、实际成交、现金、净值和失败原因。B 是第二条独立交易假设；A+R 是与 A 配对的增强政策，**不计作第三条独立策略方向**。

## B · 时序择时→长仓或现金

- [ ] 首版固定交易 **1306 TOPIX ETF**，而不是把不可直接交易的 TOPIX 指数当成交标的；以截至 `t` 收盘已知的 1306／TOPIX 日线、趋势和波动特征，预测从 `t+1` 开盘开始的预注册持有窗口方向或净优势。依 06a 的交易日折、训练截止和点时规则隔离；1306 未计分配金的账户收益局限在报告中明示。若改用 Prime 固定篮子，必须另建政策版本并定义其历史成分，不与 ETF 结果混排为同一政策。
- [ ] 实现一个具体可训练的时序择时驱动，例如在固定长度滞后路径特征上训练小型分类器；实施前登记选用的学习器（如受限容量的梯度提升分类器或小型序列网络）、窗口、目标、阈值搜索预算及资源上限。Deep Momentum Networks、Chronos 可作后续同政策挑战者，但不能直接移植期货多空头寸或让预训练模型的历史知识伪装点时可用。
- [ ] 冻结入场概率／优势门槛、退出门槛与持有／冷却规则：满足入场条件时目标长仓不超过 95% 资产，转弱／到期时卖出并留现金，其他日保持当前仓位；不做空、不借券。门槛只在训练／验证段确定，不能读折外结果后修改。缺数／模型失败时停止新增仓位，已有持仓按预注册到期或风险规则尝试退出，拒单仍记为持仓。
- [ ] 与“始终持有 1306”、固定过去动量／均线进出和全现金基线同口径比较，报告净值、回撤、空仓占比、错误退场代价、换手、费用、成交率及分年表现。方向准确率不能替代交易结果。

## A+R · 风险预测→实际降敞口

- [ ] 锁定 06b 的 A 模型、分数、Top-N、股票池、日期折、调仓日和基础退出政策；R 只读取 `t` 已知 TOPIX／行业／价量与账户状态，估计随后窗口的下侧损失或波动。实现一个实际训练的风险估计器（首版可选受限容量的分位回归／概率模型），与历史波动阈值等简单规则在相同目标上对照。阈值、风险分层、冷却期和总敞口目标在折外前冻结。
- [ ] 给出可执行映射，例如正常／高／极端风险对应 95%／45%／0% 总目标敞口；具体分层边界须由训练／验证段登记并冻结。高风险日必须生成真实减仓卖单，风险缓解后受换手／容量上限逐步补仓；“只停止新买”不算降仓。策略对单股、行业、现金、整手、订单／ADV 施加账户约束，并记录目标与拒单后的**实际**敞口。
- [ ] 扩展策略→组合规划的目标权重／总敞口意图，沿用现有账户的卖后买、`t+1` 开盘、不可交易、费用与持仓账本；不得为 R 自建交易环境。无法卖出的仓位仍承担风险，不得在报告中当作已空仓。风险模型不可用时不新增风险敞口，已有持仓按冻结规则处理。
- [ ] 在同一 A 工件、相同日期、起始现金、基础成本及压力成本下配对比较 A、A+规则风险阈值、A+AI 风险门槛；除 R 外不得改 A 的选股或调参。报告风险预测校准、实际而非目标敞口、尾部损失、净收益、回撤、费用、换手、拒单与停牌期间的风险暴露。风险指标改善不自动表示组合值得采用。

## 其他方向的后续准入卡

每条路线均要写明最小完整政策（输入→买／持／卖／现金／权重→原账本）、点时数据和许可、简单基线、资源／试验预算、独立指标及另开实施票的启动条件；没有数据时记 `data_not_ready`／`needs_rights_review`，不判方法无效。

| 方向 | 进入实施前必须解决 |
|---|---|
| 结构化财报／TDnet 文本事件 | Light 财务摘要先入库并保留开示时点与修订；TDnet 文本需数据权利、公司映射、事件标注及发布后的可交易时点。TradingAgents／FinGPT 仅提供决策或文本部件，仍需账户政策 |
| 历史关系图 | 当时已知的行业／持股／供应链边与覆盖；同特征非图和行业规则对照，不能用今天关系回填旧日 |
| AI 预测＋组合优化 | 收益／风险估计、成本及整手目标权重，和等权／逆波动对照；优化器本身不等于 AI |
| RL 直接政策 | 状态／动作／奖励与现有成交账本等价，含停牌／拒单／整手／费用；多种子、真正折外和简单政策对照 |
| 策略选择／元控制器 | 至少两套已冻结基础策略的独立折外决策记录；不能用当天未来赢家作为状态；比较固定配置和等权混合 |

RD-Agent／AutoML 因子发现和合成市场情景只作为辅助：保留所有搜索尝试，合成路径不算新增真实样本外日。具备条件的方向可独立另开票，不等待 B 或 A+R 盈利；采购数据、托管 LLM 和许可判断不由本票自动授权。

## 演示与验收

- [ ] B 和 A+R 各自在真实历史行情副本上至少完成一次训练→折外推断→完整策略决定→原账本订单／成交→实际仓位／现金／成本后净值；负收益或 `insufficient_evidence` 可接受，`not_run` 不可代替实施。
- [ ] B 的独立对照、A／A+规则风险／A+R 的配对消融按相同日期与成本展示；在报告中明确 B、A 是独立假设，A+R 是增强版本，不将三个模型名称当三套策略。
- [ ] 合成测试检查未来行情不改旧信号、训练标签不跨折；B 的开仓／退场／空仓与 R 的正常→高风险→减仓→恢复，以及风险模型失效、卖单拒绝、整手残仓、停牌时真实敞口均可追踪。
- [ ] 五条后续路线卡列明 `ready`／`data_not_ready`／`needs_rights_review` 与下一票条件；不把卡片算成已运行策略。记录测试、资源用量和失败尝试。
