# 研究保存输入身份和结果，不永久复制行情

[04b-A](../../.scratch/invest-assistant-v1/issues/04b-a-manual-range-backtest.md) 每次手选区间研究保存完整配置、实际输入覆盖／内容指纹、代码身份、每日净值和独立账本。生产行情继续覆盖存储；已完成研究直接读取保存的结果，不因后续行情修正而重新估值。输入指纹不是备份，无法恢复被覆盖行情。

## Consequences

- 内容指纹覆盖预热、股票池流动性输入、行情及调整系数、历史分类、交易日历和 TOPIX，不能用行数和截止日替代。范围可以保守包含未成交股票。
- A 每次只运行一个固定配置，在共用任务锁下读取一致输入；参数修改或重试产生新运行，保留旧指纹、配置及结果。代码身份还包含依赖锁文件。
- B 将来提供同批区间比较时，仍必须保证批次输入一致；A 不提前引入永久快照或复杂实验批次。
- 全候选观察属于后续诊断，不是 A 的持久化要求。本决定替代本编号原有的永久行情快照要求，路径保留。
