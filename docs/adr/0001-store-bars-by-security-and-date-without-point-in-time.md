# 日线行情按（证券, 交易日）覆盖存储，不做时点可复现

my-invest 用发布序号、行情版本和数据快照，保证任何一次历史研究都能按当时看到的数据重现，代价是 17 张行情表和一个 1800 行的同步模块。invest-assistant 只为个人投资决策服务，所以日线行情按（证券, 交易日）只存一份，重新抓取直接覆盖。J-Quants 追溯修正数据后，旧回测重跑的结果可能改变。回测只记下所用数据的截止日和行数，用来发现这种改变，而不是阻止它。

## Considered Options

- 沿用 my-invest 的发布序号 + 行情版本 + DataSnapshot：可复现，但表和同步流程的复杂度正是这次要去掉的。
- 每周存一份完整上市名册：股票池能按当时的分类筛选，但约 47 万行里只有 3 列被读。

## Consequences

- 没有 DataSnapshot、发布序号、原始响应存档和行情版本表。
- 信号也不存储，随时由日线行情重算；「为什么买卖」由订单上记下的理由留住。
- 市场分类是唯一例外：按市场分类区间记录变化，只在分类变化时新增一行，股票池因此仍能按当时的分类筛选，个股在 Prime / Standard / Growth 之间转移不会被看错。
