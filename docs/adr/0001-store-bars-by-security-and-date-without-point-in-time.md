# 生产日线行情按（证券, 交易日）覆盖存储，不维护全局时点版本

my-invest 用发布序号、行情版本和数据快照，保证任何一次历史研究都能按当时看到的数据重现，代价是 17 张行情表和一个 1800 行的同步模块。invest-assistant 只为个人投资决策服务，所以日线行情按（证券, 交易日）只存一份，重新抓取直接覆盖。J-Quants 追溯修正数据后，旧回测重跑的结果可能改变。模拟账户基线记下所用数据的截止日和行数，但这不能识别同日期、同行数的内容修正；04b 研究比较另按 ADR-0005 记录实际输入的内容指纹。

## Considered Options

- 沿用 my-invest 的发布序号 + 行情版本 + DataSnapshot：可复现，但表和同步流程的复杂度正是这次要去掉的。
- 每周存一份完整上市名册：股票池能按当时的分类筛选，但约 47 万行里只有 3 列被读。

研究比较记录实际输入的内容指纹，并保证同批阈值运行使用一致输入；见 ADR-0005。指纹不保存原行情，生产数据更正后不能仅凭指纹恢复旧输入。生产行情仍只保留最新值，不引入全局行情版本表或发布序号。

## Consequences

- 生产行情没有全局 DataSnapshot、发布序号、原始响应存档和行情版本表；研究首期也不要求永久归档完整行情副本。
- 日常信号随时由日线行情重算；「为什么买卖」由订单理由留住。研究运行另存逐日评级、账户状态和筛选观察，保留未形成订单的样本（ADR-0006）。
- 市场分类是唯一例外：按市场分类区间记录变化，只在分类变化时新增一行，股票池因此仍能按当时的分类筛选，个股在 Prime / Standard / Growth 之间转移不会被看错。
