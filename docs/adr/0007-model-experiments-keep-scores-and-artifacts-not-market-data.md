# 模型实验保存折外分数和模型工件，不复制行情

ticket 06a 的模型实验要能事后核对：哪个模型、在哪一天、给哪些证券打了多少分，按分数持仓据此下了哪些单、成交成什么样。每次实验保存冻结契约及其 hash、每个模型每折的模型工件（JSON）及其 hash、决策日的折外分数（带所在折和打分的工件 hash）、研究输入指纹、每次尝试的读取记录（什么时候读、各类数据覆盖哪些日子和多少行、按什么规则可用；库里没有逐行的历史可得时间，所以只记本次读取）、代码身份（应用源码和依赖锁文件的 SHA256），以及每个回放（压力场景的也一样）的账本、每日净值和逐日记录；不保存所读行情的副本。所以只声称**已保存的运行结果可审计**，不声称可以重训复现：生产行情仍按 ADR-0001 覆盖存储，ADR-0005 的指纹只能证明两次输入是否相同，不能恢复被覆盖的行情。本决定沿用 ADR-0005，不改它。

不复制行情有两个原因。一是数据权利：行情来自 J-Quants，每次实验长期另存一份所读行情，要先弄清它的利用条款允许保存哪些数据、保存多久，这件事还没有定。二是体积：真实数据上一次默认实验（2023-01-04 至 2026-10-16）要读约 528 万行日线，每个实验存一份，很快就超过主库本身。

## Considered Options

- 每个实验冻结一份所读行情：可以重训复现，但每次几百 MB，而且要先定许可允许的保存范围和保留期。
- 用 pickle 保存拟合好的模型对象：省事，但读回依赖库的版本，内容不能直接阅读和比较，读回时还会执行代码。`ridge_v1` 的拟合结果只有三十来个数，存 JSON 就够。
- 只存模型工件、不存分数，查看时现算：查看就要重新读行情，行情一修正，旧报告会悄悄改变。

## Consequences

- 工件 hash = 训练器名、参数、拟合结果和训练截止的规范 JSON 的 SHA256，读回存下的 JSON 能重算出同一个 hash。`ridge_v1` 按工件里的数值逐个特征累加打分，同一工件、同一输入的分数逐位相同。
- 只存决策日的分数，别的交易日的分数按分数持仓用不上；某折训练或打分失败就没有它的分数，失败原因记在这一折上。
- 行情没变时，把存下的分数表交给模拟账户推进同一区间，得到逐笔相同的订单和净值（有测试守住），「分数 → 交易」这一段因此可以复核。
- 重试沿用原契约，回放前比对研究输入指纹，和最早一次尝试不同就拒绝、要求登记新实验，不把不同输入的结果算成同一个实验的。
- 以后要声称可重训复现，须先定许可允许冻结的输入和保留期，再修改本决定。
